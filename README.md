## Open source · Veload

**Veload** is a Vue 3 loading toolkit I created and published to npm, with a Nuxt documentation site and live playground.

- **36 named loaders**, skeleton primitives and presets, progress indicators, loading overlays, and a loading-aware button.
- Composables for tracking concurrent operations, delaying loading indicators, and grouping loading states.
- **TypeScript declarations**, ESM/CJS exports, a shared stylesheet, and **Vue SSR support**.
- ARIA status/progress semantics, decorative modes, and **reduced-motion support**.

Includes component, composable, and SSR tests, plus packed-package consumer checks.

**Dependencies:** Vue `^3.5.2` is the only peer dependency; there are no additional runtime dependencies.

[Source code](https://github.com/Shehab-Mu/veload) · [npm package](https://www.npmjs.com/package/veload) · [Documentation & playground](https://veload-playground.vercel.app)
